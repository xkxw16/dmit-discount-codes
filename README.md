## DMIT 的折扣码体系：先理解「循环」两个字

大部分 VPS 商家的优惠码是一次性的，首单便宜，续费回到原价。DMIT 的促销码大多标着 `RECURRING`，意思是折扣跟着账单周期走——只要你不换套餐、不退款重买，后面每一次续费都按折后价扣。

这一点直接影响你的决策方式。一个 15% 的循环折扣用三年，比一个「首年 5 折」划算得多。反之，如果某个码只标了折扣幅度没写 RECURRING，那它很可能只作用于第一张账单。

另外要区分折扣和账户金返还。DMIT 的活动经常是「X% 循环折扣 + Y% 账户金返还」，返还部分会分摊到 12 个月、每月结一次，进的是账户余额而不是直接减现金。算实际优惠率时两者可以相乘：15% 折扣加 10% 返还，等于 0.85 × 0.9 = 0.765，约等于 23.5% 的综合优惠。

## 优惠码怎么用，以及为什么你的码会失效

下单流程本身不复杂，难的是别在错误的地方填。

1. 在官网配置页选好机房、线路和档位，点 Order Now 进入配置页。
2. 选付款周期。这一步很关键：`NON-MONTHLY` 这类码只认季付、半年付、年付，选月付会自动判无效。
3. 在配置页下方找到 Promo Code 输入框，填入优惠码，点 **Validate Code**。
4. 验证通过后价格会立刻刷新，同时结算页会标注这是循环折扣还是首期折扣。

报错的四种常见原因：

- **码已过期**。活动码的失效是静默的，官方不会发公告说「XX 码作废」，活动页一撤码就没了。
- **付款周期不对**。年付码填在月付订单上必然无效。
- **产品线不匹配**。Pro 的码拿去结 T1，或者拿 Lite 系列的码去结 Pro，都不认。
- **档位低于门槛**。不少码写明 STARTER 及以上或 TINY 及以上，WEE 这类最低配不参与。

还有一点容易被忽略：T1 系列的 WEE 档几乎不参与任何折扣活动。$36.90/年 的价格本身就是引流价，不要指望再叠一层。

## Pro、EB、T1 到底该选哪条线

选线的优先级高于选配置。同样 1 核 2G，Pro 和 T1 的月付价差能到两三倍，差的全部是回程路由。

**Premium（Pro）**：电信去程 CN2 GIA，联通去程 AS4837，移动去程 CMI，三网回程统一走 CN2 GIA（AS4809）。大陆访问延迟和晚高峰稳定性是三条线里最好的。

**Eyeball（EB）**：电信在 AS9929 与 AS58807 之间做负载均衡，联通走 AS9929，移动走 CMIN2。价格比 Pro 低一档，流量给得更宽，适合移动用户占多数的场景。

**Tier 1（T1）**：纯国际 BGP，没有针对中国大陆的优化。它的卖点是带宽大、流量多，而且超量之后不停机——直接降到 50Mbps 到 1Gbps 继续跑。做中转、CI/CD、备份、海外业务选它最合适。

按需求判断：大陆访客体感优先就上 Pro；预算有限但要避开最差路由就选 EB；不需要回国优化、只要大流量，T1 的 WEE 年付 $36.90 是整个 DMIT 最低的入门价。

支付方式支持支付宝、PayPal 和信用卡，国内用户用支付宝没有障碍。

退款方面，DMIT 提供 3 天内的退款，前提是使用方式符合服务条款。这条对「先买来测路由」的用法比较友好——下单当天跑一遍 looking glass 和回程测试，不合适就退。超过 3 天基本没有回旋余地。

库存是 DMIT 最容易被低估的变量。热门档位经常处于售罄状态，尤其是 Pro 和 EB 的低价档，补货频率不固定，补了也常常在几小时内清空。有明确需求的话不建议等折扣——等到的折扣可能比等不到的库存划算不了多少。

另外官方在部分新平台上会提示硬件仍处于持续优化阶段，磁盘性能和 SLA 可能低于成熟平台。拿这类机器跑重要生产业务之前，先做一轮读写和网络测试比较稳妥。

## 常见问题

**优惠码能叠加吗？**
不能。DMIT 的结算页一次只能应用一个促销码。

**年付折扣和优惠码是两回事吗？**
是两回事。很多套餐在选年付时价格会自动下降，这是官方的周期定价，不需要输码。优惠码是在这个基础上再打一层。

**老用户能用新客码吗？**
大部分活动码对新老用户都开放，但少数标明 EXISTING 或 NEW 的码有身份限制。老用户从 Lite 转 EB 这种场景，需要用专门的置换码，并且得先发工单申请。

**码填进去显示无效怎么办？**
先检查付款周期和产品线是否匹配，其次确认活动是否还在进行。如果两者都没问题，那就是码已经作废了，换一个重试。

**WEE 档能用折扣吗？**
基本不能。多个码明确写了不含 WEE，这一档本身就是最低价引流款。

选套餐这件事，路径其实很短：先定机房，再定线路，最后挑档位。折扣码只是在这条路径的末端帮你少付一点，它没法把 T1 变成 Pro，也没法让 500G 流量变成 5T。把线路选对，比多找两个码重要得多。
